# 호두마루 RE:MAKE

현재 저장소는 원작의 로비 구조를 참고해 독립적으로 다시 만든 프로토타입입니다. 원작의 이미지·음원·소스 파일을 그대로 가져오지 않습니다.

## 실행
- GitHub Pages: https://yuni2013.github.io/hodumaroo-remake/
- 개발 서버: `npm install` 후 `npm run dev`
- 빌드: `npm run build`

## 현재 연결된 기능
- 저장 데이터: 브라우저 `localStorage`
- 성장: 경험치, 레벨, 능력치
- 재화: 코인, 에너지, 상점
- 직업 구매·장착
- 장비 구매·장착·인챈트
- 영구 업그레이드
- 퀘스트: 기본·일일·주간 진행도와 보상
- 업적과 보상
- 일일 출석 보상(24시간 간격)
- 펫·유물 수집 및 장착 보너스
- 시즌 포인트와 보상 트랙
- 이벤트 진행도와 보상
- 쿠폰 코드
- 일반 전투: 웨이브·보스전·90초 도전 모드
- 웨이브 사이 특성 선택과 중복 강화
- 무한의 탑: 층 진행, 3층 단위 선택, 정수, 영구 강화, 100층 보스
- 우주 슈팅: 좌우 이동, 자동 발사, 점수와 기록
- 이동 기믹 모듈: 방향 반전, 빙판 관성, 중심 끌어당김
- 모바일 터치 패드와 키보드 조작

## 조작
- PC: WASD 또는 방향키로 이동, Space로 공격
- 모바일/태블릿: 화면 아래 방향 버튼과 공격 버튼 사용
- 전투 중 가방 버튼에서 회복 키트 사용

## 아직 콘텐츠 설계가 필요한 부분
- 현재 맵 목록에는 테스트용 훈련장만 들어 있습니다. 월드별 신규 맵·보스·도전 콘텐츠는 이름과 기믹이 확정된 뒤 추가합니다.
- 월드 2는 서로 다른 월드 1 보스 맵 11개를 클리어해야 열립니다.
- 월드 3은 상점에서 우주선을 구매하면 열립니다.
- 펫은 서로 다른 보스 맵 클리어 수, 유물은 탑 진행 층수로 해금됩니다.
- 배경음악·효과음 파일, 실제 시즌 기간 서버 동기화, 멀티플레이는 아직 연결하지 않았습니다.
- 시각 효과와 애니메이션은 추후 단계입니다.

## 저장 데이터
저장 데이터는 현재 브라우저의 `localStorage`에 보관됩니다. 브라우저 데이터 삭제 또는 다른 기기에서는 진행 상황이 자동으로 공유되지 않습니다. 로비의 설정 메뉴에서 초기화할 수 있습니다.
